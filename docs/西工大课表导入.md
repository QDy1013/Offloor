# 西工大课表（Offloor v0.20）

v0.20 新增校园数据同步，详见 [校园数据接入](校园数据接入.md)。首次建立可核对的学生身份或切换账号时，会清理旧账号或旧版未绑定身份的课表、成绩、校园存档及宿舍绑定，再保存新账号本次读取到的内容，防止部分失败时混入他人的旧数据。普通的同账号同步失败仍保留对应模块的上次结果。

## 一键导入

入口：更多 → 我的课表，学校选择“西北工业大学”。输入翱翔门户账号和密码，点击“一键导入”，App 自动完成学校认证、打开个人课表、获取默认当前学期和开学日期、保存并进入周课表。不需要手动打开教务页面、选择学期、点读取或确认预览。

学校如果要求滑块、图片验证码或二次认证，会自动显示校方页面让本人验证，通过后自动继续。应用不代做或绕过安全验证，这一步取决于校方要求。

已有有效会话时，右上角同步图标可直接重新同步；会话失效后回到账号密码表单。“课表设置 → 使用其他账号导入”切换账号。输入新凭据导入时，先清除本 App 旧 WebView 会话，避免误导入其他账号的课表。空课表、未知结构、认证失败、超时或保存失败均保留原课表。

## 考试安排、成绩与绩点

同一次“一键导入”或同步时，在已登录的教务页面里一并读取（同源请求，不另行登录）：

| 内容 | 接口 | 读取字段 |
|---|---|---|
| 考试安排（待考 + 已结束） | `/student/for-std/exam-arrange`（多身份时回退 `/exam-arrange/info/{学生}`） | `tr[data-finished]` 行：`div.time`、首列地点、第二列课程、第三列状态 |
| 各学期成绩 | `/student/for-std/grade/sheet/semester-index/{学生}` 取学期，`/grade/sheet/info/{学生}?semester=` 取成绩 | `course.nameZh/code/credits`、`courseType.nameZh`、`gaGrade`、`gp`、`gradeDetail`（含补考/缓考） |
| 总绩点 | `/student/for-std/student-portrait/getMyGrades?studentAssoc={学生}&semesterAssoc=` | `gpa` |

学生身份沿用课表导入已确认的那个，不另行猜测。三项各自独立：某项失败只保留该项的旧存档，不会被空数据覆盖；课表为空（如假期）时考试和成绩仍会保存。考试时间解析不了时原样显示，不编造日期。学期绩点按“课程绩点 × 学分”在本机计算，仅供参考。

入口：底部导航第三栏“考试成绩”（待办 / 课表 / 考试成绩）。页面分“考试安排”（下一场大卡 + 待考时间线 + 已结束折叠列表）和“成绩绩点”（总绩点、学期绩点走势、按学期折叠的成绩、课程详情弹层）。存档为应用私有目录 `academic.json`（AtomicFile，带大小上限），删除本机课表时一并删除。

v0.20 使用 `getStdInfo` 时，必须与课表页已确认的学生身份相符，只挑选姓名、学号、年级、学院、专业、班级、校区、学籍状态等实际存在的基本字段，不保存完整响应。`getMyGpa` 的前后名绩点差仍不读取；不根据旧接口推算或承诺排名。

## 周课表与交互

- 七列对应周一至周日，按节次排列。左侧显示接口提供的上课开始时间，不编造作息。
- 左滑下一周、右滑上一周；从课程色块上起手也可换周，滑动不误开详情。上下滑只滚动课表。
- 换周保留滚动位置，首尾周不能越界。顶部“本周”回到当前教学周，教学周标题可直接选周，箭头也能换周。
- 今天的日期与列高亮，同一课程颜色稳定；星期标题和课程格共用列坐标。
- 点色块查看完整课程、时间、教室、教师和具体周次。重叠课程聚为可展开的组，避免互相遮盖。
- 日期校准、未排课课程和删除课表收进设置；未排课课程不推断时间地点。

课表使用独立本机存档，不生成消息卡片、不覆盖个人档案课程。群消息中的更正不自动修改课表，需要重新同步教务系统。删除课表与“清空待办和近期消息”分别处理对应数据。

## 页面与接口依据

- [教务系统](https://jwxt.nwpu.edu.cn/student/home)；SSO `/student/sso-login`；个人课表 `/student/for-std/course-table`。
- [校方查看课表通知](https://jiaowu.nwpu.edu.cn/info/1158/29468.htm)说明通过翱翔门户进入教务系统。
- [统一认证页面](https://uis.nwpu.edu.cn/cas/login)使用 `#fm1` 表单及 `#username`、`#password`。兼容电脑版登录按钮和手机页 submit 按钮。
- [公开接口调用代码](https://github.com/qllokirin/nonebot-plugin-npu/blob/HEAD/nonebot_plugin_npu/nwpu_query.py)使用 `/student/for-std/course-table/semester/{semesterId}/print-data/{studentAssoc}?hasExperiment=true`。
- [公开字段使用代码](https://github.com/qllokirin/nonebot-plugin-npu/blob/HEAD/nonebot_plugin_npu/draw_course_schedule_pic.py)读取 `studentTableVm.activities`、作息布局及学期起始日期。

程序独立编写，公开代码仅用于确认接口和字段。读取网页默认学期及明确学生身份，不写死编号，不能唯一确定身份或识别结构时停止，不猜测。

## 凭据与存档

v0.17 申请 INTERNET 以访问校方网页。群消息识别仍在本机运行，导入组件不读取或上传群消息存档。

账号密码在本机表单短暂保留，仅交给精确的 HTTPS `uis.nwpu.edu.cn/cas/login` 及其同源表单。点击校方现有按钮，保留其加密和安全验证处理，不直接调用绕过校方处理的表单提交。提交后清除应用临时密码，不将凭据写入设置、文件、诊断日志或公开测试数据。登录页禁用截图与最近任务预览。

WebView 只允许 HTTPS 西工大域名导航，禁用文件访问、混合内容，不跳过证书错误。没有 JavaScript 原生桥接；Java 轮询固定状态和规范化课表结果，不读取 Cookie 或完整学生资料。校方会话 Cookie、站点存储可保留在本机用于后续同步，不是应用自行保存的密码。

课表独立存于应用私有目录 `timetable.json`，通过带大小上限的 AtomicFile 保存。只有非空、通过校验且具有可靠开学日期的课表会覆盖旧存档。具体上课周次原样保存，不把单双周扩大为连续周。

## 验证

自动测试均使用合成数据：

```text
node eval/test_nwpu_login.cjs     # 13项：手机/电脑按钮、同源校验、仅提交一次、安全验证、状态不含凭据
node eval/test_nwpu_import.cjs    # 30项：学期、身份、周次、作息、非法及过期响应
node eval/test_nwpu_academic.cjs out.json   # 考试/成绩/绩点解析、部分失败、过期会话
```

`android/test/AcademicTest.java` 验证考试成绩存档、合并规则（失败项保留旧数据）和学期绩点计算，可传入上一条生成的 `out.json` 做 JS/Java 对接检查。

2026-11-06 已在真机（vivo V2505A，测试版）由本人登录一次导入：考试安排、两个学期的成绩和总绩点均正确读取并显示，底部三栏切换与返回键行为正常，浅色/深色均已截图核对。会话过期、断网和假期空课表下“只更新考试成绩”的路径尚未实测。

`android/test/TimetableTest.java` 验证日期、周次、作息、存档格式、重叠布局和学校边界，共29项。JVM 类路径需 org.json，编译包含 `Timetable.java`、`TimetableLayout.java`、`TimetableSchool.java`；Android 自带 org.json。导入测试脚本可传输出路径以生成该测试使用的模拟 JSON。

2026-11-06 已由本人在手机输入账号密码并点击一次“一键导入”，自动回到已保存的周课表。有效会话下单次点击同步也已通过。此前已验证结束进程后重新打开可恢复存档。没有把真实账号、个人课表、会话或密码写入公开测试数据。

## 构建

独立测试版：`python android/build.py --sdk <SDK路径> --preview`，生成 `nopalou-preview.apk`，应用 ID 为 `com.nopalou.preview`，桌面名称及图标沿用仓库“Offloor”，测试标记放在应用内。可与原版并存，不读取或覆盖原版待办；测试课表无需开启通知读取权限。

标准版需原签名：`python android/build.py --sdk <SDK路径> --keystore <旧版签名密钥库路径>`。本次调试签名与仓库旧 APK 不同，不可直接覆盖安装；不要为安装而卸载旧版，以免丢失本机待办。
