# 校园数据接入（v0.21）

本轮目标：把正常登录后本人可见且能识别的信息接入 Offloor，提供原生离线展示。新增代码和安装包已构建；用户本轮无法连接测试手机，新增个人数据没有进行真实账号验收。不能把下列服务目录当成全部接口已接通。

## 使用

底部“校园”进入总览，点击模块查看字段、表格、公告链接及最后一次成功读取的时间。“全部同步”先使用原来的西工大教务统一登录流程，再建立门户会话、读取本人应用目录、依次完成各服务的SSO跳转。各系统有自己的会话，不代表要重复输入账号密码。入口未适配、网络失败、加载占位页或未识别页面不会显示成成功或零条记录，也不会默认解释成需要独立账号。

应用共用WebView的校方会话存储，采用顶层页面跳转建立各服务自己的会话。门户中观察到的链接、应用目录名称与URL、校方统一认证按钮及应用图标用于正常认证交接；只触发匹配服务的普通页面事件。应用图标异步获取票据并使用 `window.open` 时，将其受信任的校内导航保留在当前WebView，不导出或保存票据。没有为各个系统编造CAS服务地址，也没有把同一个密码转发给不同业务站点。

CAS中转页先等待跳转。只有统一认证站点的密码表单稳定出现，才提示统一登录已失效，并提供一次重新统一登录后继续同步。业务站点出现密码框时，先查找其统一认证入口，并重试门户入口；仍没有找到时标记为入口待适配。校方验证码或二次验证会暂停自动同步，完成后继续，不作为“另一个账号”处理。

校方页面在可识别内容加载后自动保存，也可点“读取此页”。App 只读取已加载页面，不自动操作选课、评教提交、续借、预约、取消、充值或支付。动态页面初次没有读到时，需打开具体信息页；没有凭空猜测未提供的接口。

宿舍电量点“查询 / 选择宿舍”，依次使用校方返回的 `name/value` 选项选择校区、楼栋、房间。绑定成功后保存在本机，后续可查询或重新选择。未绑定不会猜测用户住址，也不会批量枚举房间。

| 体育场馆、综测与奖助 | 从翱翔门户实际服务链接或应用图标进入；学工平台已知入口 `https://xgpt.nwpu.edu.cn/` 采用校方统一认证 | 提供SSO交接、入口发现和结构化页面读取，尚无专用API/真实字段验收 |

信息按“字段 / 表格 / 链接”展示；表格每次展开30条。单页最多12张表、每表200条、12列，每个单元格最多600字，超出行数会标记截断。当前不自动翻页、不遍历站点、不处理PDF附件正文或扫描图片、不保证覆盖全校所有系统。新页面或变更结构可继续增加专用适配器。

## 存档与失败处理

`campus.json` 使用应用私有目录和 AtomicFile，带大小上限；每个模块保存自己的成功时间，本次失败保留原内容和原成功时间，另记失败状态。空白、认证页和纯加载页不能覆盖成功存档。新版本内置本轮验证过的公开公告链接快照，带采集时间，可在安装后离线查看；个人信息必须本人登录后同步。

学生身份仅以学校范围内的 SHA-256 标记用于账号隔离。显式换账号时清除旧 WebView 会话；确认新学生身份后清理旧账号模块及宿舍绑定。其他页面的异步保存检查启动时的账号标记，拒绝旧账号的迟到结果。

仅允许 HTTPS 西工大域名导航与受限读取；登录凭据不由新模块读取/导出，无 JavaScript 原生桥。只从已观察到的链接发现入口，拒绝包含认证票据或明确写操作的自动链接。排除密码、验证码、身份证、家庭信息、银行卡、支付码等标签/列，以及脚本、隐藏输入和隐藏单元格内容。没有把真实个人账号、Cookie、密码或个人页面写入仓库。

## 验证

- Android完整源码编译通过，独立测试APK构建及签名验证通过。
- `node eval/test_nwpu_login.cjs`：13项；`test_nwpu_import.cjs`：30项；`test_nwpu_academic.cjs`：20项。
- `node eval/test_nwpu_campus.cjs [fixture.json]`：17项，使用真实Chromium和合成HTML/网络响应，覆盖身份匹配、来源限制、只跟随已观察读链接、页面与部分接口失败、脚本/隐藏内容、公开链接和行数上限。
- `CampusDataTest`：14项，覆盖失败保留成功时间、跨账号清理、拒绝旧回调、空成功/恶意来源拒绝和浏览器输出到Java的衔接。
- `AcademicTest`：15项；`TimetableTest`：29项。合计138项检查通过。
- v0.21新增 `test_nwpu_sso.cjs`：12项，使用合成统一认证与两个合成服务验证共享浏览器会话、独立服务会话、普通认证跳转、入口发现、只触发一次官方按钮及异步应用图标导航。所有认证测试均为合成环境，没有使用真实账号。浏览器拦截环境用页面导航模拟认证重定向链，未替代真实服务验收。
- `CampusAuthTest`：10项，覆盖瞬时中转页、稳定中央登录表单、验证码等待和业务登录入口的分类。累计160项检查通过。
- 真实公网仅验证了公开公告HTML、网络登录入口和电量校区选择查询的状态。新增个人模块、真实跨系统SSO、各设备原生界面及校园网环境尚待验收。

运行浏览器检查需Playwright及Chromium。可通过环境变量 `PLAYWRIGHT_MODULE` 指向已有Playwright模块、`CAMPUS_BROWSER` 指向Chrome/Edge可执行文件。JVM检查使用项目原有的 `org.json` 测试类路径。`inspect_campus_public.cjs` 可对下载的公开HTML做无网络真实DOM验证。

## 构建

```text
python android/build.py --sdk <SDK路径> --preview --keystore <已有测试签名密钥库> --out <输出目录>
```

应用ID `com.nopalou.preview`，版本0.21，可与原版并存；复用原测试密钥以便兼容已有测试版。测试版本的存档和校方会话与原版分开，在测试版统一登录一次即可开始同步。不能因为源码构建通过而宣称所有服务已实际抓取成功。
