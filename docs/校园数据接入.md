# 校园页（v0.30）

校园页保留网费、电费、一卡通、空闲教室和校车。网费、电费、一卡通集中在校园账户卡；校园服务展示空闲教室和校车。待办截止、借阅、学籍、培养方案、学业进度、独立选课/评教目录、综测奖助、座位/场馆预约、公告、校历和门户其他应用不再展示或自动读取。历史模块仍保留在原始存档中。

## 展示与来源

| 内容 | 卡片直接展示 | 来源和实际范围 |
|---|---|---|
| 网费 | 账户余额 | 优先读取已登录门户首页的网费组件；已在本人真机读取和保存，不补零 |
| 电费 | 剩余电量、更新时间，不展示宿舍资料 | v0.28 起参照翱翔助手：先走一卡通统一登录入口（`berserker-auth/cas/login/supwisdom`）取得 `synjones-auth` 令牌，再打开一卡通“交电费”页（`toAppitem?feeitemid=182`），读页面按本账号宿舍显示的剩余电量，不需要逐级匹配房间；令牌只在内存中使用。手动关联过房间的仍按房间查；读不到时退回逐级匹配。查询失败不再删除已关联的房间。真机（11-08）读到 4.22 度 |
| 一卡通 | 校园卡余额、卡片状态 | 读取门户 HotData 组件的明确字段；已在本人真机读取和保存，不遍历旧账单 |
| 空闲教室 | 当天所选校区、地点、起止时间与实际返回教室 | 每次打开重新查询，可选长安或友谊校区和当天起止时间；v0.30增加地点下拉，选项来自本次返回的教学楼，并依据明确楼座字段或教学教室编号细化到A/B/C/D座（如B1-302归入B座），体育馆编号不推断楼座；切换地点只筛选本次结果，重新查询或修改校区、时间会重置为全部地点；默认接下来一小时，临近午夜仍保持当天，旧结果不混入新时段 |
| 校车 | 按方向突出下一班、上车地点和全部发车时间 | 可切换工作日和周末；使用已核对的官方学期内表本地计算，时间到自动切换；详情不再展示横向大表格和记录数量 |

页面去掉服务数量、资料目录和同步说明的大块展示，以实际数值为主。缺失数据明确说明未读到；有上次数据则保留时间。正常使用无需手动同步。

## 校车数据

来源：[校方校历、校车时刻表公告](https://xygg.nwpu.edu.cn/info/1003/22073.htm)。2026-11-08实际读取该公告，公告标注2026-08-27，所附运行表注明自2025-03-31起实行。原图保存于本轮本地审查材料，应用只内置按原表核对的50条学生可参考发车记录及必要说明，不内置校历图片。

数据文件为 android/app/assets/campus-bus.json，包括工作日友谊→长安16班、长安→友谊17班，周末及节假日友谊往长安8班、长安往友谊9班（排除7:00教师专用车）。限量学生校车的时间区间仅作文字说明，不当作确定班次参与下一班计算。

默认根据北京时间的星期选择工作日或周末表；法定节假日、调休、寒暑假或临时调整仍以学校通知为准，卡片明确提示并提供官方原表入口。校园页每分钟重算下一班。公共时刻表无需校园登录，也不在每次同步时重复加载整张校历、时刻表图片。

## 自动读取和精简

保留三路读取、共用校方会话、观察请求和DOM稳定结果、分批保存和失败重试。校园读取只进入选定服务。未绑定宿舍时允许一个电费内部依赖，只保留校区、楼栋、房间等位置字段，不显示独立住宿模块，也不读取综测奖助。原有课表、考试成绩页仍独立保留并更新。

网费与校园卡余额先保存并显示，不重复打开服务页。门户占位路由不再覆盖实际入口，避免反复跳转。教务同站点依次读取，成绩历史安排在校园项目之后；普通校园项目有90秒总时限。升级或进程被系统结束后，失效任务会自动重新建立，不再仅凭旧标记等待30分钟。

登录阶段只建立已核对的学生身份，不再额外请求学籍、培养方案和其他已删除模块。门户目录只用于定位保留服务的统一认证入口，不再把其他应用加入队列。

网费、一卡通优先读取当前账户和近期默认结果，不遍历旧学期、历史上网记录或无关预约。空闲教室使用独立查询，不加入全量后台同步队列；每次查询只接受本次结果，未返回的教室不推断为占用。不会触发缴费、充值、预约、提交评教或选课等写操作。

加载时仅过滤用于展示的副本，未选模块、动态应用目录及其路由仍保留在完整磁盘存档。新数据合并到完整存档后保存，避免删入口连带删除历史数据。首次写入前的版本快照、读取异常时暂停覆盖等保护见[应用内更新](应用内更新.md)。
