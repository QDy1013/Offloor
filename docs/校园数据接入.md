# 校园页（v0.26）

校园页固定保留用户选择的六项，顺序为网费、电费、一卡通、空闲教室、校车、待办截止。删除借阅、学籍、培养方案、学业进度、独立选课/评教目录、综测奖助、座位/场馆预约、公告、校历和门户其他应用的展示与自动读取入口。

## 展示与来源

| 内容 | 卡片直接展示 | 来源和实际范围 |
|---|---|---|
| 网费 | 账户余额 | 优先读取已登录门户首页的网费组件；已在本人真机读取和保存，不补零 |
| 电费 | 剩余电量、更新时间，不展示宿舍资料 | 同源电量查询；已绑定可直接查询。本轮账号尚未自动匹配电表，没有拿到真实电量 |
| 一卡通 | 校园卡余额、卡片状态 | 读取门户 HotData 组件的明确字段；已在本人真机读取和保存，不遍历旧账单 |
| 空闲教室 | 教室数量和明确查询条件 | 使用实际教务入口及其原有查询函数；默认长安校区接下来一小时，已在正式版真机读取和保存 |
| 校车 | 两个方向各自表列下一班，以及乘车地点 | 根据已核对的官方学期内表本地计算，时间到自动切换，不是车辆实时定位 |
| 待办截止 | 事项名称和明确截止时间 | 仅从本人评教、选课等页面保留未完成且尚未截止的事项；无明确时间不编造倒计时 |

页面去掉服务数量、资料目录和同步说明的大块展示，以实际数值为主。缺失数据明确说明未读到；有上次数据则保留时间。正常使用无需手动同步。

## 校车数据

来源：[校方校历、校车时刻表公告](https://xygg.nwpu.edu.cn/info/1003/22073.htm)。2026-11-08实际读取该公告，公告标注2026-08-27，所附运行表注明自2025-03-31起实行。原图保存于本轮本地审查材料，应用只内置按原表核对的50条学生可参考发车记录及必要说明，不内置校历图片。

数据文件为 android/app/assets/campus-bus.json，包括工作日友谊→长安16班、长安→友谊17班，周末及节假日友谊往长安8班、长安往友谊9班（排除7:00教师专用车）。限量学生校车的时间区间仅作文字说明，不当作确定班次参与下一班计算。

默认根据北京时间的星期选择工作日或周末表；法定节假日、调休、寒暑假或临时调整仍以学校通知为准，卡片明确提示并提供官方原表入口。校园页每分钟重算下一班。公共时刻表无需校园登录，也不在每次同步时重复加载整张校历、时刻表图片。

## 自动读取和精简

保留三路读取、共用校方会话、观察请求和DOM稳定结果、分批保存和失败重试。校园读取只进入选定服务。未绑定宿舍时允许一个电费内部依赖，只保留校区、楼栋、房间等位置字段，不显示独立住宿模块，也不读取综测奖助。原有课表、考试成绩页仍独立保留并更新。

网费与校园卡余额先保存并显示，不重复打开服务页。门户占位路由不再覆盖实际入口，避免反复跳转。教务同站点依次读取，成绩历史安排在校园项目之后；普通校园项目有90秒总时限。升级或进程被系统结束后，失效任务会自动重新建立，不再仅凭旧标记等待30分钟。

登录阶段只建立已核对的学生身份，不再额外请求学籍、培养方案和其他已删除模块。门户目录只用于定位保留服务的统一认证入口，不再把其他应用加入队列。

网费、一卡通优先读取当前账户和近期默认结果，不遍历旧学期、历史上网记录或无关预约；教室与截止事项可继续读取必要分页。不会触发缴费、充值、预约、提交评教或选课等写操作。

升级加载存档时自动清理未选模块、动态应用目录及其路由；必要宿舍位置字段仅用于电费匹配。账户标记与六项有效数据保留。课表、成绩存档不因这次校园页精简而删除。

## 验证

- CampusScopeTest 20项、CampusAutoTest 38项，以及数据格式、认证状态检查通过。覆盖六项清单、失效占位入口、电费资料隐藏、查询条件不能误作教室结果和同站点调度。
- eval/test_campus_focus.cjs 13项：门户余额归属、折叠校园卡字段、真实教务菜单、默认教室查询和精简范围。
- 2026-11-08连接 vivo 真机，以现有本人会话验证：正式0.26版已显示并保存网费余额、校园卡余额和状态、长安校区明确日期与一小时时间段的空闲教室结果，自动更新结束。校车为核对过的内置官方时刻表。未要求再次输入校园密码。
- 电费接口可访问，但本轮账号没有可确认的电表关联，因此没有电量数值。教室早期请求曾遇校方412，正式版复测成功；部分评教页面仍未返回可解析的截止数据，部分读取时不据此断言没有待办。
- 临时诊断包和截图仅存本地审查目录，不进入源码或更新目录；正式包不开放调试或导出校园读取 Activity。
