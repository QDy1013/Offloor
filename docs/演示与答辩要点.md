# 演示与答辩要点（v0.29 候选版）

本轮候选版尚未发布到正式更新渠道。指标使用 README 当前表格，不沿用历史版本数字。

## 30 秒讲清价值

群通知、学习平台和教务系统里散落着需要学生处理的事情。Offloor 把可获取的内容整理成事项，保留来源，并追踪改期、取消和接龙进展。基础识别在本机完成；可选 AI 使用用户配置的云端接口。

## 演示前检查

1. 核对安装渠道与版本；独立测试包的数据与正式版分开。
2. 核对通知使用权、服务连接、电池与自启动设置。连接正常不等于所有群消息都能获取。
3. 填好档案；AI 未开启时不要演示截图识别或宣称云端增强生效。
4. 使用内置离线演示时，主动说明是样例回放，不是实时读取真实微信。
5. 准备演示录像。不能把 JVM 测试通过表述为所有手机上的通知读取、保活和交互都通过。

## 三分钟流程

| 时间 | 内容 | 展示重点 |
|---|---|---|
| 0:00–0:30 | 群里事项分散的具体场景 | 哪件事、什么时候、来源在哪 |
| 0:30–1:30 | 内置离线演示 | 作业、考试、接龙卡及原文追溯 |
| 1:30–2:15 | 播放消息更新 | 改期更新原卡、接龙已接后撤提醒 |
| 2:15–2:40 | 修正、完成、恢复或加入日历 | 人工修正与误识别恢复路径 |
| 2:40–3:00 | 效果与边界 | 合成评测不代表真实群聊；通知覆盖有限 |

v0.29 新增的模糊更正与过期 AI 保护已通过引擎测试。本轮未进行真机交互验收，现场演示前需另行核对。

## 常见问题

**真实群聊效果如何？**

当前缺少独立真实群聊测试集。合成留出集的非噪声文本有 82.32% 与训练集重复，只能报告该数据上的结果。不能把“未见过句子”子集的 100% 当作泛化结论。

**用了什么模型？**

本机规则、逻辑回归与结构化抽取。可选云端模型复判不确定消息、补全卡片、转写截图。没有实现方案书里的端侧大模型、BERT 或 LoRA 训练。

**隐私如何处理？**

AI 默认关闭，基础识别在本机运行；开启 AI 后，待复核消息原文、发送者、群名、部分上下文及所选截图会发送到用户配置的接口。课表与校园数据通过校方网页获取。不能笼统宣称“所有内容不出手机”。

**能保证不漏吗？**

不能。聊天应用未给通知正文、免打扰群不发通知、系统后台限制都可能导致缺失。截图分享是需要用户主动操作的补充，不等于自动覆盖。当前没有无障碍读屏入口，也不能读取微信语音文件。

**更正消息指向不清怎么办？**

v0.29 对多张同样匹配的待办保留原时间并显示待核对，不猜着改或删。原发送者使用“作业”泛称时，只在最近一周内唯一作业的条件下处理。回复人的名称提示只是规则线索，不是可靠身份认证。

**新版本各项指标都提升了吗？**

没有。更保守的更正匹配降低了合成集上的时间与变更处理得分，完整数值与原因见 README 和《日常使用前可靠性修复》。

## 现场故障

- 未连接：查看自动读取自检并按实际提示设置；系统仍拒绝时使用录像或明确标注的离线样例。
- 无消息正文：如已配置支持图片的 AI，可主动分享截图。不要使用已移除的读屏或粘贴入口作为演示方案。
- 不确定时间：展示原文与人工修正，不用猜测的时间代替。
