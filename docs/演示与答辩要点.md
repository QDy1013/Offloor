# 演示与答辩要点

本文只写现场要说的话和要避开的坑。数字来自 `README.md` 的「实测指标」，不在这里另造。

## 30 秒讲清价值

群里一晚上几百条消息，真正要你做的只有几件事。「offloor」在手机本地把这几件事挑出来，做成卡片：交什么、什么时候交、在哪交。接龙里没有你，会提醒"你还没接"。消息识别可离线工作；新增课表导入需要访问校方教务网页，保存后可离线查看。

## 演示前检查（按顺序）

1. **别重启手机。** 部分国产手机（如 vivo）重启后会拒绝通知监听，现场救不回来。
2. 打开主界面，看"通知读取"是不是**已连接**。不是的话，点一下按它的引导重新授权。
3. 填好"我的档案"（姓名、班级、课程），否则判断"和你有没有关系"不准。
4. 手机放勿扰，关掉其他会弹通知的 App，避免演示时被打断。
5. 准备一份录好的视频，真机出问题时直接放。

## 三分钟流程

| 时间 | 做什么 | 要点 |
|---|---|---|
| 0:00–0:30 | 说痛点，翻几屏群消息 | 让评委感到"爬楼" |
| 0:30–1:30 | 主界面跑离线演示 | 作业卡、考试卡、接龙卡依次出现；回放 APK 的 272 条脚本则是丢掉 74 条噪声后出 4 张卡 |
| 1:30–2:15 | 点"播放群消息更新" | 作业和考试时间被老师更正后，卡片跟着变；接龙里没有你就出提醒，你被补进名单后提醒消掉 |
| 2:15–2:40 | 点"已完成"、加入日历 | 完成的卡划线变淡排到最后；日历里不写群消息原文 |
| 2:40–3:00 | 讲评测数字和限制 | 见下 |

主界面的离线演示里**有考试卡**：老师发期中考试通知（时间、教二305、带学生证），随后老师说改到后天上午 10 点，原卡跟着变。这是最直观的展示点。回放 APK 的 272 条脚本里没有考试通知，只出 4 张作业和接龙卡。想在真机群里再试，让同学发一条老师身份的考试通知即可，但这一步没在真机验证过，只当备选。

## 评测怎么说

- 合成留出集：召回 97.8%，精确 95.9%（Python 版）；APK 里跑的 Java 版是 97.51% / 95.91%。
- 必须主动说明：数据是模板生成的，留出集里 82.3% 的句子在训练集出现过，所以数字证明流水线自洽，**不代表真实群聊**。只看没见过的句子，召回 97.5%。
- 手写 60 条分布外集不报单个数，报两个极端假设：发送者全设老师，召回 100%、精确 88.5%；全设学生，召回 73.9%、精确 100%。这说明"谁发的"对结果影响很大。
- 原来报的 23/23 已作废（发送者是按答案设的），被问到就说明这件事。

## 可能被问到的问题

**Q：为什么不用大模型？**
手机本地跑，要离线、省电、不上传聊天内容。当前用规则 + 逻辑回归 + 个人档案，方案书里的端侧大模型和小 BERT 没有接入。

**Q：怎么保证不漏？**
召回是第一指标。时间说不清就标"待确认"，不乱猜；不确定的宁可出卡让人看一眼。

**Q：别人冒充老师说"取消"怎么办？**
更正和撤销只认可信发送者（老师、班长等），并且要指得清是哪一条，同群有多场考试时须唯一匹配考试名称。

**Q：隐私？**
本地处理；加入日历不写群消息原文；"读当前群"读到的内容先预览、你确认才导入，预览只存内存，5 分钟后作废。

**Q：真实群聊上表现如何？**
没测过，这是已知限制。合成数据偏模板化。下一步要靠真人的群来测。

**Q：能读微信群吗？**
靠通知读取和"读当前群"。免打扰的群通知里没有内容，要用"粘贴群消息"补。系统通常不给发送者信息，所以读屏结果的发送者需要手动补。

## 现场出问题怎么办

- 通知没读到：用"粘贴群消息"手动录一条，或用离线演示。
- 状态显示未连接：点状态行按引导重新授权；不行就放录好的视频。
- 被问到没做的东西：直接说"没做，原因是……"，对照 `docs/方案书对照.md`，不要硬说做了。
