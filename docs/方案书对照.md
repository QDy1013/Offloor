## 一句话总结还差什么

1. **已完整落地的核心路线**：本机三级流水线（规则 + 40KB 线性模型 + 抽取/状态机）+ 编入 APK 的 `llama.cpp` GBNF 端侧推理与可选云端复核 + 课表/待办/空教室/研修室跨源闭环 + 30 天过期清理、Keystore 加密与脱敏诊断。
2. **尚未完成、材料中绝不夸大的部分**：
   - 未做蒸馏与 LoRA/QLoRA 训练；
   - 缺少脱敏后的真实大学班级群聊采集集与第一周真机通知覆盖率统计；
   - 缺少端侧 1.5B 小模型在真实 Android 手机上的推理耗时、内存峰值、电量开销以及「纯本机 vs 加 1.5B vs 加云端」三组同集真机对照数据；
   - `v0.80+` 暖纸极简界面截图与真机全链路（通知保活、校园网/一卡通余额同步）仍需真机验收补齐。
