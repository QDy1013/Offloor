# v0.29 日常使用前可靠性修复候选版

2026-11-09，基于主分支 bdb8508。优先修复自动改错事项、AI 旧结果写回和通知去重与保存顺序问题。本轮没有发布到 GitHub 或正式更新渠道。

## 本轮行为

- 同群两份实验报告都匹配“实验报告延期”时，保留各自时间，标为待核对并显示变更原文；后续明确说出报告名时，只更新对应卡片并解除其待核对状态。模糊撤销也不会随意删其中一张。
- “更正一下，作业截止改到……”仅能指向同一发送者最近一周内唯一的一份作业；多份作业、其他发送者或其他群不能用泛称猜目标。
- AI 请求记录本机卡片快照与数据批次。改期、人工修正、其他更新之后返回的旧结果不写回；清空后在途旧结果不能重新创建卡片。校验信息随队列保存，不发给模型；正常未过期请求可在重启后继续写回。旧版本未携带快照的请求保持本机识别结果。
- AI 必须明确返回布尔判定与有效把握；缺字段、非法把握、低把握结果不修改卡片。非法截止时间不能把已有候选时间标为确定。关闭 AI 后，后台 Job 不再继续下一批文字请求，也不写回其在途文字结果。
- 清空待办时同时清空 AI 队列。通知正文交给引擎成功后才记去重；卡片保存失败时不先提交去重存档，后续支持的通知或历史扫描会重试保存。监听服务销毁后同步清除“已连接”状态。
- 增加统一离线回归入口；自动打包流程在回归失败时停止发布。手写集改期场景失败时返回非零退出码。

## 验证

```bash
python -X utf8 eval/run_checks.py --out checks.json
python -X utf8 eval/run_java_eval.py --out java-comparison.json
python android/build.py --sdk <Android SDK> --preview --out <构建目录>
```

Windows / JDK 21 / Android SDK 34。核心检查共 56 组（含一次统一 Java 编译），全部通过；新 Step45Test 覆盖模糊更正、明确更正恢复、低把握与非法时间、过期 AI 结果、清空与重启等场景。额外使用 Android SDK 与 org.json 的 JVM 实现直接运行 AiResponseTest，10 项解析与队列序列化检查通过。APK 已实际编译、签名并通过签名校验。

时间评分的历史验收用“总分必须高于 0.9085”间接判断评分器正确，这个条件不能隔离引擎行为。现改为独立测试：正确更新为更正时间的卡计 1，仍保留旧时间的卡计 0，连续更正回溯到原始事项；同时仍报告完整合成集分数，未修改金标准来提高分数。

本轮未进行真实手机上的连续使用、杀进程或重启保活验收，未调用真实云端接口；不能据此宣称应用已完全完善或没有漏事。通知监听仍受免打扰、隐藏正文和手机系统后台限制。新测试包与正式应用分别存储数据，不读取正式版待办；它沿用此前预览包签名，可更新原预览包。
